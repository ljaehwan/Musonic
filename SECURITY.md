# Security reports

Please email **hwandevlog@gmail.com** for suspected credential exposure, authentication problems or other security issues. Include the affected version, reproduction steps and likely impact. Use synthetic credentials in examples.

Do not put a working password, token, private server address or exploit against someone else's server in a public issue. We can arrange a safer way to share details if needed.

Security fixes target the latest published version. There is no guaranteed response time or paid bug-bounty program.
