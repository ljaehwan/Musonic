# Musonic artwork

The ribbon mark is available as SVG and PNG. Android uses native vector drawables and adaptive icon layers in `app/src/main/res`.

The primary color is rose `#D52D4D`, with dark text `#1C1C20` and white `#FFFFFF`. Keep clear space around the mark and preserve its proportions.

- `musonic-symbol.svg`: transparent symbol.
- `musonic-icon.*`: rounded-square icon, 1024 px PNG.
- `musonic-store-icon.*`: full-bleed square icon, 512 px PNG.
- `musonic-logo.*`: wordmark for light backgrounds.
- `musonic-logo-white.*`: wordmark for dark backgrounds.

Wordmarks use outlined paths derived from Noto Sans Bold. See [FONT-NOTICE.txt](FONT-NOTICE.txt).
