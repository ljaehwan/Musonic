# Support Musonic

Musonic is free and has no ads. All features are available without payment.

A useful bug report, a translation, testing with another Subsonic server, or sharing the project with someone who hosts their own music helps it grow. A GitHub star is welcome too.

Financial sponsorship is being set up through GitHub Sponsors. A donation link will be added here once the account is ready to accept payments. There is no active donation page linked from this project yet.

For app questions, use [Issues](https://github.com/ljaehwan/Musonic-android/issues/new/choose). For private support or privacy requests, email **hwandevlog@gmail.com**.
